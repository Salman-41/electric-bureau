# Project rules

## Editorial and design

- Make a distinctive, editorial experimental museum; give THE ELECTRIC BUREAU its own visual identity.
- Do not use generic AI-generated website layouts, arbitrary section numbers, or meaningless technical labels.
- Build from real, sourced historical information. Distinguish documented facts from interpretation and counterfactual speculation.
- Let each artifact drive its own interaction. Avoid decorative interaction that obscures the object or its history.
- Design for keyboard, screen-reader, reduced-motion, contrast, touch, and small-screen use.
- Use WebGL lightly and only when it materially helps explain an object. Provide a usable non-WebGL fallback.

## Scope and workflow

- Local development only. No hosting, deployment, or cloud infrastructure.
- Keep development testing minimal; do comprehensive testing at the final stage.
- Clear rights for each specific image, audio file, video, or model before incorporating it. An open object record does not itself grant image or model rights.
- Do not label a technology a failure unless evidence supports that description. Describe adoption, limits, and replacement accurately.
- Keep research, asset, and license decisions documented in `docs/research/` and `data/objects.json`.
