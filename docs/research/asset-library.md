## Download and file handling

- Download from the rights-owning institution’s object/media page, not a search thumbnail, third-party mirror, or CDN URL without provenance.
- Preserve the source URL, object identifier, creator/maker, date, media rights statement, download date, and any attribution alongside local asset files.
- For the Smithsonian stereoscope scan, first retrieve the model through its own Smithsonian 3D object page; record the offered file format and license/rights text in the asset manifest. The public page confirms download/reuse availability but this brief has not downloaded or technically validated the package.
- Do not embed restricted assets from museum pages, Smithsonian Magazine, commercial image agencies, or Google Arts & Culture without permission. Link out to those records instead.
- If web use becomes commercial, apply the same rights check; “portfolio/demo” does not automatically make an unlicensed media file reusable.
